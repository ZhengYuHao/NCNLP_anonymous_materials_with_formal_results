# Third-party sources and redistribution

Workflow requirements were derived from the public n8n template library:
https://n8n.io/workflows/

Source identifiers and available hashes are included in the requirement records
and `data/provenance/formal_source_set.csv`. This package does not claim authorship
of the original workflows. The original source metadata should be consulted for
each template's creator and applicable reuse terms. No blanket license for those
third-party workflows is inferred merely from public accessibility.

Raw upstream workflow exports and deployment assets are omitted. Source descriptions
appear only where retained in the supplied derived requirements/evidence records.
Before public redistribution, the artifact owner should confirm rights to share
these derived records and the implementation, and choose an appropriate license.

External libraries named in requirements files retain their own licenses. This
snapshot does not vendor those dependencies. The reference to a public model API
does not provide an API subscription, redistribute model weights or grant model
access rights.
